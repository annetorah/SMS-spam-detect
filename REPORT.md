# SMS Spam Detection Using Natural Language Processing

## 1. Introduction
This project applies Natural Language Processing (NLP) to SMS text classification.

## 2. Objective
Classify an SMS as:
- Ham / legitimate
- Spam

## 3. Dataset
UCI SMS Spam Collection.

## 4. Method
1. Load the dataset.
2. Explore the labels and data quality.
3. Remove duplicates.
4. Clean and normalize text.
5. Tokenize, remove stop words, and lemmatize.
6. Split into training and testing data.
7. Convert text to TF-IDF numerical vectors.
8. Train a Multinomial Naive Bayes classifier.
9. Evaluate the classifier.
10. Save the trained model.
11. Use the same saved model in the web application.

## 5. Results
Run the notebook and copy the actual accuracy, precision, recall, F1-score, and confusion matrix into this section.

## 6. Conclusion
The project demonstrates an end-to-end NLP classification system and a simple interactive application for testing new SMS messages.
